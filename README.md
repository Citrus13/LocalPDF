# LocalPDF

Windows環境で完全ローカル動作する、軽量かつ高機能なPDF加工・注釈・閲覧ツールです。
ネットワーク接続や外部サーバーへのアップロードを一切行わず、すべての処理がお使いのPC内で完結します。

---

## 主な特徴

- 高速なPDF閲覧・ページ操作（回転、削除、並べ替え、結合、分割抽出）
- 直感的な注釈・手書き描画（ペン、蛍光ペン、文字入れ、図形、白塗り消し、画像挿入）
- 全操作対応の元に戻す・やり直す（Ctrl+Z / Ctrl+Y）
- PDFと画像（JPG/PNG）の相互変換
- エクスプローラーからのファイル直接ドラッグ＆ドロップ対応

---

## 画面構成と基本操作

### 1. ファイルを開く
- エクスプローラーからPDFファイルまたは画像ファイルを画面上に直接ドラッグ＆ドロップします。
- または、上部ツールバーの「開く」ボタンから選択します。

### 2. ページの移動と表示
- マウスホイール: 上下端に達すると前後のページへ自動で移動します。
- Ctrl + マウスホイール: 画面の拡大・縮小（ズーム）を行います。
- 手のひらスクロール: スペースキーを押しながらドラッグ、またはマウスの中ボタン（ホイールクリック）ドラッグで画面を掴んで自由にスクロールできます。
- ツールバーの「前頁」「次頁」ボタン、またはキーボードの PageUp / PageDown でも移動できます。

### 3. ページ操作
- 回転: 「右90°回転」または「左90°回転」ボタン（Ctrl+R / Ctrl+Shift+R）
- 並べ替え: 左側のサムネイル一覧でページをドラッグして任意の場所へドロップします。またはツールバーの「前へ」「後へ」ボタン（Alt+↑ / Alt+↓）でも移動できます。
- 結合: 「PDF結合」ボタンを押すと、現在表示しているページの直下に別のPDFを挿入します。
- 画像追加: 「画像追加」ボタンからJPGやPNGを選択し、新しいページとして挿入します。
- 分割・抽出: 「抽出」ボタンからページ番号（例: 1 や 1-3）を指定して、そのページのみを別名PDFとして書き出します。
- 削除: 「ページ削除」ボタン（Deleteキー）で現在のページを削除します。

### 4. 注釈・編集ツール
ツールバーの各ボタン、または対応するキーボードショートカットを押して使用します。

| ツール | キー | 説明 |
|---|---|---|
| 選択・移動 | V | 配置した文字や図形をクリックして選択・移動します |
| 手のひら | H | 画面をドラッグしてスクロール移動します |
| ペン | P | フリーハンドの手書き線を描きます |
| 蛍光ペン | Y | 文字の上から半透明のハイライト線を引きます |
| 消しゴム | E | マウスでなぞった手書き線や図形を直接消去します |
| 文字入れ | T | クリックした位置に文字入力ボックスを作成します |
| 四角形 | R | ドラッグした範囲に四角枠を描きます |
| 白塗り消し | W | 個人情報や不要な箇所をドラッグして白く塗りつぶして隠します |
| 画像挿入 | - | お手持ちの画像をページ上に貼り付けます |

### 5. 色・太さ・文字サイズの変更
- 上部ツールバーの「色」ボタンをクリックするとカラーパレットが開き、好きな色を選べます。
- 「太さ」の数値を変更すると、ペンの太さや枠線の幅が変わります。
- 「文字サイズ」の数値を変更すると、テキストの大きさが変わります。
- 既に配置したオブジェクトを選択した状態で色や太さを変更すると、そのオブジェクトの見た目がリアルタイムに変わります。

### 6. 編集のやり直し・コピー・削除
- 元に戻す: Ctrl + Z で直前の作業を取り消します。
- やり直す: Ctrl + Y で取り消した作業を復元します。
- コピー＆ペースト: 選択ツール（V）でオブジェクトを選び、Ctrl + C でコピー、Ctrl + V で複製します。
- 削除: オブジェクトを選択して Delete キー、またはオブジェクトを右クリックして「このオブジェクトを削除」を選びます。

### 7. 保存・エクスポート
- PDF出力: 「PDF出力」ボタンを押し、注釈や回転を反映した完成PDFを保存します。
- 画像出力: 「画像出力」ボタンを押し、全ページを高解像度連番画像（PNG形式）としてフォルダへ書き出します。

## 開発環境・ビルド方法

- 言語: C++20
- フレームワーク: Qt 6.8.3 (Core, Gui, Widgets, Pdf, PdfWidgets)
- コンパイラ: MSVC 2022 (x64)
- ビルドシステム: CMake 3.20以上, Ninja

ビルド手順:
```cmd
build.bat
```
生成物: `build/LocalPDF.exe`
